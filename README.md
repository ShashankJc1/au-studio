# AU Studio website

Static website for AU Studio, an interior design and build studio. Plain HTML, CSS and JavaScript, with GSAP, ScrollTrigger and Lenis vendored in `assets/vendor/`.

**Live:** https://shashankjc1.github.io/au-studio/

## Status
Version 3, a fresh design. The home page is up for review; the remaining pages (Studio, Services, Projects, Contact, Careers) follow once the home page design is approved.

## Files
- `index.html`: home page
- `assets/css/site.css`: styles
- `assets/js/site.js`: interactions (hero slideshow, text and image reveals, pinned project gallery, parallax, testimonials, form validation)

## Before launch
- Photography is from Unsplash as a placeholder; replace with AU Studio's own project photos.
- Contact details, figures, testimonials and project names are sample copy.
- Connect the enquiry form to a form service (e.g. Web3Forms or Formspree) in `assets/js/site.js`.
